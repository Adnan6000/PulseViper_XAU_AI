# Code of Conduct

## Our Commitment

PulseViper XAU AI is a research-first engineering project. We want discussions, reviews, issues, and contributions to remain professional, technically rigorous, and respectful.

Everyone participating in this repository is expected to help maintain a constructive environment regardless of experience level, background, identity, or point of view.

## Expected Behavior

Contributors should:

- Be respectful, precise, and evidence-driven.
- Focus criticism on code, experiments, documentation, or engineering decisions rather than individuals.
- Clearly distinguish verified results from assumptions, hypotheses, and opinions.
- Respect the project's protected research boundaries, frozen artifacts, and one-time evaluation rules.
- Avoid publishing credentials, account information, broker secrets, private datasets, or other sensitive information.
- Report security-sensitive issues privately whenever possible.
- Keep financial-performance claims factual and reproducible.
- Never present historical results as guaranteed future outcomes.

## Unacceptable Behavior

The following are not acceptable:

- Harassment, discrimination, personal attacks, intimidation, or abusive language.
- Deliberately bypassing research safeguards.
- Encouraging unauthorized use of protected VALIDATION or TEST data.
- Misrepresenting experimental results, model status, or live-trading readiness.
- Publishing passwords, tokens, API keys, private account information, or confidential data.
- Spam, deceptive promotion, or unrelated solicitation.
- Knowingly submitting malicious or destructive code.

## Research and Trading Safety

PulseViper is currently a research and validation project.

Contributions must not imply that:

- the project is live-trading ready;
- historical results guarantee profitability;
- VALIDATION or TEST may be reused for performance-driven tuning;
- frozen safety components may be changed without explicit authorization.

When artifact identity, feature ordering, research provenance, or protected-data state is uncertain, contributors should fail closed and investigate before continuing.

## Enforcement

Repository maintainers may edit, reject, remove, or close comments, issues, pull requests, or contributions that violate this Code of Conduct.

Repeated or serious violations may result in restrictions from participating in the project.

## Reporting

For security vulnerabilities, follow `SECURITY.md`.

Do not publicly disclose security-sensitive information, account information, credentials, or exploit details.

For conduct concerns, contact the repository maintainer privately through the contact methods available on the maintainer's GitHub profile.

## Scope

This Code of Conduct applies to:

- GitHub issues
- Pull requests
- Code reviews
- Discussions
- Documentation contributions
- Other official PulseViper project collaboration spaces
